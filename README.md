<ja-JP>
v1.0.0 リリース！
「Hyphen Scan」は、カメラを向けるだけで英数字を読み取り、読みやすいハイフン区切り形式に自動変換するスキャナーアプリです。

主な機能：
・自動ハイフン挿入：長い英数字も3桁区切りで見やすく表示。
・リアルタイムスキャン：カメラをかざすだけで瞬時にテキスト化。
・スキャン間隔調整：読み取りスピードを1秒?10秒の間で自由に設定可能。
・クリップ機能：読み取った大事な値をボタン一つで画面に固定表示。
・英語対応：数字だけでなく、アルファベットを含む文字列にも対応。

WiFiパスワードやシリアルコードの確認など、日常のちょっとした入力作業にお役立てください。
